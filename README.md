# Landin | Persian Landing Page

A Persian landing page website built with HTML5 and CSS3, featuring a right-to-left (RTL) layout and a clean user interface.

## Preview

![Landin Website Preview](screenshots/landin-preview.png)

## About The Project

Landin is a front-end practice project focused on recreating and implementing a landing page design for a Persian website.

The project includes different sections for presenting services, products, marketing features, and online business solutions.

## Features

- Persian language support
- Right-to-left (RTL) layout
- Custom typography using Estedad font
- Navigation menu
- Product and service sections
- Marketing and promotional sections
- Login page interface
- Custom images and SVG icons

## Built With

- HTML5
- CSS3

## Getting Started

To run this project locally:

1. Clone the repository:

```bash
git clone https://github.com/behrouamin-ship-it/landin.git
```

2. Open the project folder.

3. Open `land.html` in your browser.
